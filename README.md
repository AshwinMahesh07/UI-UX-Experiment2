# UI-UX-Experiment2

## Aim:
To design basic mobile and web layouts using Gestalt principles, UI elements, interaction behaviors, usability principles, and a brand logo created using Canva.

## Algorithm:

1.Select and study the case study.
2.Apply Gestalt principles to organize the layout.
3.Add suitable UI elements and design patterns.
4.Design mobile and web layouts.
5.Add interactions and usability features.
6.Create and add the brand logo using Canva.
7.Test the design and prepare the report with the GitHub URL.
